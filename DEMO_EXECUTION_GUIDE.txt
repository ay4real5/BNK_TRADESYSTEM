TROUBLESHOOTING
══════════════════════════════════════════════════════════════════════

Issue: "No OAuth access token"

Solution:
1. Visit http://localhost:8000/auth/ctrader/login
2. Complete OAuth flow
3. Verify: curl http://localhost:8000/api/v1/ctrader/status

───────────────────────────────────────────────────────────────────────

Issue: "Risk check failed"

Possible causes:
- Daily trade limit reached
- Daily loss limit exceeded
- Account locked (cooldown)

Solution:
1. Check risk state: curl http://localhost:8000/api/v1/execution/status
2. Reset daily state (if testing):
   - Delete risk_state row in database
   - Or wait for next trading day

───────────────────────────────────────────────────────────────────────

Issue: "Order submission failed"

Possible causes:
- Invalid credentials
- Network error
- cTrader API down
- Invalid order parameters

Solution:
1. Check logs for detailed error
2. Verify cTrader connection
3. Test with smaller position size
4. Check symbol is tradeable

───────────────────────────────────────────────────────────────────────

Issue: "Position not syncing"

Possible causes:
- Remote position ID not stored
- Network error
- cTrader API rate limit

Solution:
1. Manually trigger sync:
   POST http://localhost:8000/api/v1/execution/sync-positions
2. Check database for position_id_X secret
3. Verify position exists in cTrader
