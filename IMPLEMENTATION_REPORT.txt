USER ACTION REQUIRED
══════════════════════════════════════════════════════════════════════

To complete the setup and verify the integration:

[STEP 1] Add Credentials to .env
   
   Edit .env and add your cTrader credentials:
   
   CTRADER_CLIENT_ID=your_client_id_here
   CTRADER_CLIENT_SECRET=your_client_secret_here
   CTRADER_ENV=demo

[STEP 2] Start Backend Server
   
   uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

[STEP 3] Complete OAuth Flow
   
   Visit in your browser:
   http://localhost:8000/auth/ctrader/login
   
   - Log in with cTrader demo account
   - Grant requested permissions
   - Wait for redirect to callback
   - Verify success message

[STEP 4] Call Status Endpoint
   
   curl http://localhost:8000/api/v1/ctrader/status | jq
   
   Expected response:
   {
     "connected": true,
     "token_valid": true,
     "environment": "demo",
     "account_id": "1234567",
     "accounts": [...],
     "last_heartbeat": "2026-02-25T10:30:45Z",
     "token_expires_at": "2026-02-25T11:30:00Z"
   }

[STEP 5] Run Automated Tests
   
   python scripts/test_ctrader_oauth.py
   
   Verify all tests show PASS

[STEP 6] Paste Status JSON
   
   Copy the JSON response from /api/v1/ctrader/status
   Redact any sensitive tokens
   Paste here to confirm setup complete
